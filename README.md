# 💡 Idea-Tracer AI

> **"단순 노동자가 아닌, 아이디어 씨앗을 심은 사람을 찾아냅니다!"**  
> 대화 속 아이디어가 어떻게 최종 결과물로 진화했는지 추적하고 팀원 개개인의 숨은 기여 유형(페르소나)을 입증하는 공정한 협업 분석 시스템

---

## 🌟 주요 기능

1. **아이디어 타임라인 & 계보도 (Idea Genealogy & Visual Map)**
   - 채팅창의 전환점 제안 및 문제의식 발의를 감지하여 `[아이디어 씨앗]`으로 지정
   - 보고서 문장 선택 시 `[아이디어 씨앗]` ➔ `[구조 설계]` ➔ `[팩트 검증]` ➔ `[문장 윤문]` 인과 진화 경로를 실시간 하이라이트
   - 생키(Sankey) 다이어그램으로 전체 프로젝트 아이디어 전이 맵 시각화

2. **유형별 협업 캐릭터 리포트 (4대 페르소나 카드)**
   - 💡 **아이디어 개척자 (Pioneer)**: 새로운 키워드, 방향성, 전환점 아이디어 씨앗 최다 제시
   - 📐 **구조 설계자 (Architect)**: 보고서 목차를 잡거나 의견을 개요 형태로 체계적 정리
   - 🔍 **팩트체커 (Critic)**: 오류 지적, 공식 통계, 학술 논문 및 출처 링크 연결
   - ✍️ **문장 연마사 (Polisher)**: 구어체와 비문을 학술적/보고서용 격식체 어조로 매끄럽게 변환
   - 팀원별 5각 방사형(Radar) 역량 다이어그램 및 모둠 종합 레이더 분석 제공

3. **공정 기여도 심층 분석 & 무임승차/단순노동 왜곡 교정**
   - 기존의 단순 글자 수/타수 측정 방식과 Idea-Tracer AI의 인과 가중치 평가 비교
   - 재평가 격차(+%p)를 산출하여 숨은 기여 인재를 입증하고 숟가락 얹기 방지
   - 수행평가 지도 교사용 생활기록부/세특 종합 관찰 기록 문구 자동 생성

## 🚀 빠른 시작 (Quick Start)

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 환경 변수 설정 (.env)
`.env` 파일에 API 키를 설정하거나(선택사항), 미입력 시 내장된 **스마트 로컬 인과분석 엔진**으로 즉시 오프라인 구동할 수 있습니다.
```env
AI_PROVIDER=gemini
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash
```

### 3. 애플리케이션 실행
```bash
streamlit run app.py
```
브라우저에서 `http://localhost:8501`로 접속하여 원클릭 샘플 시나리오 또는 메신저 대화(.txt)를 분석해보세요!
